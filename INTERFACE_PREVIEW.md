## 🖼️ Описание компонентов

### 1. Заголовок
- Название системы с градиентным фоном
- Краткое описание функциональности

### 2. Секция загрузки модели (⚙️ Model Configuration)
- **Model Weights**: Загрузка файла .pth с обученными весами
- **Config File**: Опциональный файл конфигурации .yaml
- **Model Architecture**: Выбор архитектуры из выпадающего списка
  - `fasterrcnn_resnet50_fpn`
  - `fasterrcnn_resnet50_fpn_v2`
- **Load Model**: Кнопка загрузки модели
- **Model Status**: Индикатор статуса (успех/ошибка)

### 3. Вкладки детекции

#### 📷 Image Detection
**Левая панель (Ввод):**
- Область загрузки изображения (drag & drop)
- Слайдер настройки порога (0.1 - 1.0)
- Кнопка "Detect Objects"

**Правая панель (Вывод):**
- Обработанное изображение с рамками детекций
- Markdown с подробной статистикой:
  - Общее количество детекций
  - Количество по каждому классу
  - Средняя уверенность

#### 🎥 Video Detection
**Левая панель:**
- Область загрузки видео
- Слайдер настройки порога
- Кнопка "Process Video"

**Правая панель:**
- Обработанное видео с аннотациями
- Статистика обработки:
  - Всего кадров обработано
  - Кадров с детекциями
  - Среднее количество детекций

#### 📹 Webcam Detection
- Инструкции по использованию webcam через CLI
- Пример команды для real-time детекции

### 4. Секция инструкций (📖 Instructions)
Сворачиваемая секция с:
- Пошаговым руководством
- Советами по использованию
- Информацией о форматах файлов

### 5. Футер
- Ссылки на GitHub репозиторий
- Ссылки на документацию

## 🎨 Стилизация

### Цветовая схема
- **Фон заголовка**: Градиент фиолетовый (#667eea → #764ba2)
- **Кнопки**: Синий (primary variant)
- **Текст статуса**: 
  - ✅ Зеленый для успеха
  - ❌ Красный для ошибок
  - ⚠️ Желтый для предупреждений

## 📱 Адаптивность

Интерфейс адаптируется под размер экрана:
- **Desktop**: Две колонки (ввод/вывод рядом)
- **Tablet**: Две колонки с меньшими отступами
- **Mobile**: Одна колонка (ввод сверху, вывод снизу)

## 🎯 Пример использования

### Шаг 1: Загрузка модели
```
1. Открыть "Model Configuration"
2. Загрузить best_model.pth
3. Нажать "Load Model"
4. Увидеть: "✅ Model loaded successfully! Device: cuda:0"
```

### Шаг 2: Детекция на изображении
```
1. Перейти на "Image Detection"
2. Загрузить изображение fire.jpg
3. Установить threshold = 0.5
4. Нажать "Detect Objects"
5. Увидеть результат с красными рамками вокруг огня
```

### Пример вывода статистики
```
📊 **Detections found:** 3

- **fire**: 2 (avg confidence: 0.85)
- **smoke**: 1 (avg confidence: 0.67)
```

## 📝 Заметки для разработчиков

Для создания скриншотов:
1. Запустите интерфейс: `python launch_ui.py`
2. Откройте `http://localhost:7860`
3. Загрузите тестовую модель
4. Сделайте скриншоты основных экранов
5. Сохраните в папку `docs/screenshots/`

Рекомендуемые скриншоты:
- `01_main_page.png` - Главная страница
- `02_model_loading.png` - Загрузка модели
- `03_image_detection.png` - Детекция на изображении
- `04_video_processing.png` - Обработка видео
- `05_results_stats.png` - Результаты и статистика
