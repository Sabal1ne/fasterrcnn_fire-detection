# 🌐 Веб-интерфейс для детекции пожара

Удобный веб-интерфейс на базе Gradio для использования модели Faster RCNN Fire Detection.

## 🚀 Быстрый старт

### Запуск интерфейса

```bash
python launch_ui.py
```

Или напрямую:

```bash
python app.py
```

Интерфейс откроется по адресу: `http://localhost:7860`

## ✨ Возможности

### 📷 Детекция на изображениях
- Загрузка изображений через браузер
- Настройка порога уверенности
- Визуализация результатов в реальном времени
- Подробная статистика обнаружений

### 🎥 Обработка видео
- Загрузка видео файлов
- Прогресс-бар обработки
- Статистика по всему видео
- Сохранение результата

### ⚙️ Настройки
- Загрузка собственных весов модели
- Выбор архитектуры модели
- Настройка порога детекции
- Поддержка GPU/CPU

## 📖 Инструкция

### 1. Загрузка модели

1. Нажмите "Model Configuration"
2. Загрузите файл весов (.pth)
3. (Опционально) Загрузите конфигурацию (.yaml)
4. Выберите архитектуру модели
5. Нажмите "Load Model"

### 2. Детекция на изображениях

1. Перейдите на вкладку "Image Detection"
2. Загрузите изображение (drag & drop или кнопка)
3. Настройте порог детекции (0.1 - 1.0)
4. Нажмите "Detect Objects"
5. Просмотрите результаты и статистику

### 3. Обработка видео

1. Перейдите на вкладку "Video Detection"
2. Загрузите видео файл
3. Настройте порог детекции
4. Нажмите "Process Video"
5. Дождитесь завершения обработки
6. Просмотрите результат и статистику

## 💡 Советы

### Настройка порога
- **0.3**: Больше детекций, возможны ложные срабатывания
- **0.5**: Сбалансированный вариант (рекомендуется)
- **0.7**: Только уверенные детекции

### Производительность
- GPU значительно ускоряет обработку
- Для длинных видео рекомендуется GPU
- Обработка изображений быстрая даже на CPU

### Форматы файлов
- **Изображения**: JPG, PNG, JPEG
- **Видео**: MP4, AVI
- **Веса**: .pth файлы из обучения
- **Конфигурация**: .yaml файлы

## 🔧 Требования

Убедитесь, что установлен Gradio:

```bash
pip install gradio>=3.50.0
```

Или установите все зависимости:

```bash
pip install -r requirements.txt
```

## 📝 Примеры использования

### Без предобученной модели
Интерфейс запустится с COCO pretrained моделью:
```bash
python launch_ui.py
```

### С обученной моделью
1. Обучите модель: `python train.py --config data_configs/fire.yaml`
2. Запустите интерфейс: `python launch_ui.py`
3. Загрузите веса из `outputs/training/your_project/best_model.pth`

## 🌐 Публичный доступ

Для публичного доступа к интерфейсу используйте параметр `share=True` в `app.py`:

```python
demo.launch(share=True)
```

Gradio сгенерирует публичную ссылку, доступную в течение 72 часов.

## ❓ Частые вопросы

**Q: Интерфейс не открывается**
A: Проверьте, что порт 7860 не занят. Измените порт в `app.py` или `launch_ui.py`.

**Q: Модель не загружается**
A: Убедитесь, что файл весов совместим с выбранной архитектурой.

**Q: Медленная обработка видео**
A: Используйте GPU или уменьшите разрешение видео.

**Q: Нет детекций**
A: Попробуйте уменьшить порог детекции или переобучите модель на вашем датасете.
