# ✅ Чеклист развертывания

Используйте этот чеклист для развертывания нейросети на хостинге.

## 🚀 Быстрый старт (1 минута)

- [ ] Открыть терминал в папке проекта
- [ ] Запустить: `./launch_public.sh` (Linux/Mac) или `launch_public.bat` (Windows)
- [ ] Дождаться появления публичной ссылки
- [ ] Скопировать ссылку вида `https://xxxxx.gradio.live`
- [ ] Поделиться ссылкой с пользователями
- [ ] ✅ Готово! Нейросеть доступна 72 часа

## 🔒 С аутентификацией (опционально)

- [ ] Установить переменную: `export GRADIO_AUTH=username:password`
- [ ] Запустить приложение
- [ ] Сообщить пользователям логин и пароль

## 🤗 Hugging Face Spaces (Постоянный хостинг)

### Подготовка
- [ ] Создать аккаунт на [huggingface.co](https://huggingface.co)
- [ ] Создать новый Space
- [ ] Выбрать SDK: Gradio
- [ ] Выбрать Hardware: CPU basic (или GPU)

### Развертывание
- [ ] Клонировать Space: `git clone https://huggingface.co/spaces/USER/NAME`
- [ ] Скопировать файлы проекта в Space
- [ ] Переименовать `README_HF.md` в `README.md`
- [ ] Добавить файлы: `git add .`
- [ ] Закоммитить: `git commit -m "Initial deployment"`
- [ ] Отправить: `git push`
- [ ] Дождаться автоматической сборки
- [ ] ✅ Space готов! Ссылка: `https://huggingface.co/spaces/USER/NAME`

### Добавление весов модели (опционально)
- [ ] Создать папку: `mkdir -p outputs/training/fire_model`
- [ ] Скопировать веса: `cp /path/to/best_model.pth outputs/training/fire_model/`
- [ ] Закоммитить и отправить

## 🐳 Docker (Универсальное решение)

### Локально
- [ ] Установить Docker
- [ ] Запустить: `docker-compose up -d`
- [ ] Открыть: `http://localhost:7860`
- [ ] ✅ Работает локально

### С публичным доступом
- [ ] Настроить порт-форвардинг на роутере
- [ ] Настроить firewall
- [ ] Получить публичный IP или домен
- [ ] Настроить Nginx с SSL (опционально)

### На cloud сервере
- [ ] Арендовать сервер (AWS/GCP/DigitalOcean)
- [ ] Установить Docker на сервере
- [ ] Скопировать проект на сервер
- [ ] Запустить: `docker-compose up -d`
- [ ] Настроить домен и SSL
- [ ] ✅ Production ready!

## 🚂 Railway.app

- [ ] Создать аккаунт на [railway.app](https://railway.app)
- [ ] Нажать "New Project"
- [ ] Выбрать "Deploy from GitHub"
- [ ] Выбрать репозиторий
- [ ] Railway автоматически обнаружит `railway.json`
- [ ] Дождаться развертывания
- [ ] Получить ссылку вида: `https://your-app.railway.app`
- [ ] ✅ Готово!

### Настройка переменных (опционально)
- [ ] Открыть Variables в Railway Dashboard
- [ ] Добавить: `GRADIO_AUTH=username:password`
- [ ] Перезапустить сервис

## 🎨 Render.com

- [ ] Создать аккаунт на [render.com](https://render.com)
- [ ] Нажать "New +" → "Web Service"
- [ ] Подключить GitHub репозиторий
- [ ] Render обнаружит `render.yaml`
- [ ] Дождаться развертывания
- [ ] Получить ссылку: `https://fire-detection.onrender.com`
- [ ] ✅ Готово!

**Примечание**: Бесплатный план "засыпает" после 15 минут бездействия

## ☁️ Google Cloud Run

### Предварительные требования
- [ ] Установить Google Cloud SDK
- [ ] Создать проект в GCP
- [ ] Включить Cloud Run API

### Развертывание
- [ ] Собрать образ: `gcloud builds submit --tag gcr.io/PROJECT/fire-detection`
- [ ] Развернуть: `gcloud run deploy fire-detection --image gcr.io/PROJECT/fire-detection`
- [ ] Получить URL от Cloud Run
- [ ] ✅ Масштабируемое решение готово!

## 🔍 Проверка работы

После развертывания проверьте:
- [ ] Открывается главная страница
- [ ] Можно загрузить модель
- [ ] Детекция на изображении работает
- [ ] Детекция на видео работает (если есть)
- [ ] Аутентификация работает (если включена)
- [ ] Доступ с мобильного устройства
- [ ] Производительность приемлемая

## ⚠️ Устранение проблем

### Приложение не запускается
- [ ] Проверить логи: `docker-compose logs` или в dashboard платформы
- [ ] Проверить наличие всех зависимостей
- [ ] Проверить порт не занят

### Медленная работа
- [ ] Рассмотреть использование GPU
- [ ] Оптимизировать размер модели
- [ ] Использовать ближайший регион

### Нет доступа из интернета
- [ ] Проверить firewall правила
- [ ] Проверить GRADIO_SERVER_NAME=0.0.0.0
- [ ] Проверить порт открыт
