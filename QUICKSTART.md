# 🚀 Быстрый старт - Веб-интерфейс

Это пошаговое руководство поможет вам быстро запустить веб-интерфейс для детекции пожара.

## 📋 Предварительные требования

1. Python 3.7 или выше
2. Установленные зависимости (см. ниже)

## 🔧 Установка зависимостей

### Вариант 1: Все зависимости
```bash
pip install -r requirements.txt
```

### Вариант 2: Минимальные зависимости для интерфейса
```bash
pip install numpy opencv-python pillow pyyaml gradio torch torchvision
pip install albumentations
```

## 🎯 Запуск интерфейса

### Windows
Дважды кликните на файл:
```
launch_ui.bat
```

Или в командной строке:
```bash
python launch_ui.py
```

### Linux/Mac
```bash
./launch_ui.sh
```

Или:
```bash
python3 launch_ui.py
```

## 🌐 Доступ к интерфейсу

После запуска откройте браузер по адресу:
```
http://localhost:7860
```

## 📝 Первое использование

### Без обученной модели (тестирование)

1. Запустите интерфейс
2. Интерфейс загрузится с COCO pretrained моделью
3. Загрузите любое изображение для тестирования

### С обученной моделью (рекомендуется)

1. Обучите модель:
```bash
python train.py \
  --model fasterrcnn_resnet50_fpn_v2 \
  --config data_configs/fire.yaml \
  --epochs 50 \
  --batch-size 4 \
  --project-name my_fire_detection
```

2. Запустите интерфейс:
```bash
python launch_ui.py
```

3. В интерфейсе:
   - Откройте секцию "Model Configuration"
   - Загрузите файл весов: `outputs/training/my_fire_detection/best_model.pth`
   - Нажмите "Load Model"
   - Дождитесь сообщения "✅ Model loaded successfully!"

4. Используйте вкладку "Image Detection" или "Video Detection"

## 🎨 Использование интерфейса

### Детекция на изображениях

1. Перейдите на вкладку "📷 Image Detection"
2. Перетащите изображение в область загрузки или нажмите для выбора файла
3. Настройте "Detection Threshold" (рекомендуется 0.5)
4. Нажмите "🔍 Detect Objects"
5. Результат появится справа с подробной статистикой

### Обработка видео

1. Перейдите на вкладку "🎥 Video Detection"
2. Загрузите видео файл
3. Настройте "Detection Threshold"
4. Нажмите "🔍 Process Video"
5. Следите за прогрессом обработки
6. Просмотрите результат и статистику

## 💡 Советы для начинающих

### Настройка порога
- **Начните с 0.5** - это сбалансированное значение
- Если слишком много ложных срабатываний → увеличьте до 0.6-0.7
- Если пропускаются объекты → уменьшите до 0.3-0.4

### Производительность
- Первая детекция может быть медленнее (инициализация модели)
- GPU ускоряет процесс в 5-10 раз
- Для видео рекомендуется использовать GPU

### Поддерживаемые форматы
- **Изображения**: .jpg, .jpeg, .png
- **Видео**: .mp4, .avi, .mov

## ❓ Решение проблем

### Ошибка: "Module not found"
Установите недостающий модуль:
```bash
pip install <module_name>
```

### Ошибка: "Port 7860 is already in use"
Порт занят другим приложением. Измените порт в `app.py`:
```python
demo.launch(server_port=7861)  # Используйте другой порт
```

### Интерфейс не открывается автоматически
Откройте браузер вручную и перейдите на `http://localhost:7860`

### Медленная обработка
- Убедитесь, что используется GPU (если доступен)
- Уменьшите разрешение входных изображений/видео
- Закройте другие ресурсоемкие приложения

### Ошибка при загрузке модели
- Проверьте путь к файлу весов
- Убедитесь, что выбрана правильная архитектура модели
- Проверьте, что файл не поврежден
