# Faster RCNN Fire Detection

Веб-интерфейс для обнаружения пожара и дыма с использованием нейронной сети Faster RCNN.

## Использование

1. Загрузите обученные веса модели (.pth файл)
2. Выберите архитектуру модели
3. Нажмите "Load Model"
4. Загрузите изображение или видео для анализа
5. Настройте порог детекции и нажмите "Detect Objects"

## Обучение собственной модели

Для обучения модели на своих данных, клонируйте репозиторий:
https://github.com/Sabal1ne/fasterrcnn_fire-detection

Следуйте инструкциям в README.md для подготовки данных и обучения.
